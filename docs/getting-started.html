01시작 전 준비

  • Python 3.11 이상이 필요합니다. 이 프로젝트는 Python 3.13.15와 Textual 8.2.8에서 동작을 검증했습니다.
  • 저장소를 clone하거나 다운로드한 뒤 압축을 풀어 agent-console 폴더에서 터미널을 여세요.
  • 최초 설치 시에는 패키지를 다운로드할 인터넷 연결이 필요합니다.

Windows에서는 폴더를 연 뒤 우클릭 메뉴의 ‘터미널에서 열기’를 사용할 수 있습니다. 현재 폴더에 pyproject.toml, src, tests가 보이면 준비된 것입니다.

PowerShell · Python 확인
python --version
macOS / Linux · Python 확인
python3 --version

아래 명령은 모두 저장소 최상위 폴더에서 실행하세요. 이미 설치를 마쳤다면 03 · 첫 화면 띄우기로 이동하세요.

02설치하기

명령을 한 줄씩 실행하세요. 가상환경은 이 프로젝트가 사용할 Python과 패키지를 별도 폴더에 모으는 공간입니다.

1. 프로젝트 전용 가상환경 만들기

PowerShell
python -m venv .venv
macOS / Linux
python3 -m venv .venv

2. Agent Console 설치하기

PowerShell
.\.venv\Scripts\python.exe -m pip install -e .
macOS / Linux
.venv/bin/python -m pip install -e .

-e .는 현재 폴더의 프로젝트를 설치합니다. 소스를 수정하면 다시 설치하지 않아도 반영됩니다. 이 안내서는 가상환경을 activate하지 않고 실행 파일의 위치를 직접 지정합니다.

3. 설치 확인하기

PowerShell
.\.venv\Scripts\agent-console.exe --help
macOS / Linux
.venv/bin/agent-console --help

확인할 결과: 도움말에 replay와 run 명령이 보이면 설치 완료입니다.

03첫 화면 띄우기

replay는 이미 저장된 이벤트 파일을 읽는 명령입니다. 아래 샘플은 가상 데이터이므로 실제 Agent 실행이나 credential 준비가 필요 없습니다.

성공한 실행 살펴보기

PowerShell · 성공 샘플
.\.venv\Scripts\agent-console.exe replay tests/fixtures/successful_developer_run.jsonl
macOS / Linux · 성공 샘플
.venv/bin/agent-console replay tests/fixtures/successful_developer_run.jsonl

확인할 결과: COMPLETED · Events 12 · Errors 0 · Elapsed 4.315s

화면은 결과를 읽을 수 있도록 열린 상태로 유지됩니다. q를 눌러 닫은 다음 다른 명령을 실행하세요.

실패한 실행도 확인하기

PowerShell · 실패 샘플
.\.venv\Scripts\agent-console.exe replay tests/fixtures/failed_run.jsonl
macOS / Linux · 실패 샘플
.venv/bin/agent-console replay tests/fixtures/failed_run.jsonl

확인할 결과: FAILED · Events 8 · Errors 2. 샘플에 의도적으로 실패 이벤트가 들어 있습니다.

필요할 때 붙이는 옵션

옵션언제 사용하나요?
--delay 0.2파일의 각 줄을 0.2초 간격으로 읽어 흐름을 천천히 봅니다. 기록된 시간에 맞춘 재생은 아닙니다.
--plain전체 화면 대신 최종 텍스트 보고서를 출력하고 종료합니다.
--tui대화형 터미널 화면을 명시적으로 사용합니다. stdin replay에는 사용할 수 없습니다.

예를 들어 성공 샘플 명령 끝에 --plain을 붙이면 간단한 보고서로 확인할 수 있습니다.

04화면 읽는 법

화면 영역의미
Run 선택 / 상태어떤 실행을 보고 있는지와 전체 결과를 표시합니다. 여러 run이 있으면 상단에서 선택합니다.
Timeline실행 기록을 sequence 순서로 보여줍니다. 오류는 색상과 ERROR 문구로 구분합니다.
ComponentsMain, Developer, Codex, Test 등의 마지막 lifecycle 상태를 표시합니다.
Current activity가장 최근의 non-run 이벤트를 작업 설명으로 보여줍니다.
Run summary기록된 경과 시간, 이벤트 수, 오류 수, 전체 결과를 요약합니다. Issues는 입력·관측 진단 수입니다.

Tab 영역 이동 · ↑ ↓ 목록 탐색 · q 종료 · Ctrl + C 중단

어떤 component가 실패해도 재시도 후 run 전체는 성공할 수 있습니다. 전체 결과는 run.completed, run.failed, run.cancelled를 기준으로 판단합니다. 종료 이벤트가 없으면 Incomplete로 표시합니다.

권장 터미널 크기는 80열 × 24행 이상입니다. Elapsed는 이벤트에 기록된 시간이며 replay를 기다린 실제 시간과는 다릅니다.

05실시간으로 보기

run은 외부 명령을 실행하고 그 명령의 stdout에서 JSONL 이벤트를 받습니다. 먼저 샘플을 한 줄씩 내보내는 예제 프로그램으로 연결을 확인하세요.

PowerShell · 실시간 샘플
.\.venv\Scripts\agent-console.exe run -- .\.venv\Scripts\python.exe -u examples/emit_fixture.py tests/fixtures/successful_developer_run.jsonl
macOS / Linux · 실시간 샘플
.venv/bin/agent-console run -- .venv/bin/python -u examples/emit_fixture.py tests/fixtures/successful_developer_run.jsonl

이벤트가 차례로 나타나고 마지막에 COMPLETED / Process exit 0이 표시됩니다. q로 화면을 닫으세요.

-- 앞은 Agent Console의 옵션, 뒤는 실행할 외부 명령입니다. Python의 -u는 출력을 모아두지 않고 바로 전달하도록 합니다.

06실제 Agent 연결하기

샘플이 정상 동작하면 외부 프로그램의 공개 JSONL 출력 명령으로 교체하세요. ai-agent마다 실행 옵션이 다를 수 있어 여기서는 특정 CLI 옵션을 가정하지 않습니다.

명령 형식 · 꺾쇠 부분은 실제 값으로 교체
.\.venv\Scripts\agent-console.exe run -- <실행파일> <인자들>
명령 형식 · 꺾쇠 부분은 실제 값으로 교체
.venv/bin/agent-console run -- <실행파일> <인자들>
  • producer는 schema_version 1의 JSON 한 개를 한 줄에 출력해야 합니다.
  • stdout에는 JSONL만, 일반 진단은 stderr로 보내세요. 각 이벤트를 즉시 flush해야 실시간으로 보입니다.
  • 외부 명령은 현재 작업 폴더와 환경변수를 상속합니다. 다른 프로젝트의 실행 파일·스크립트는 필요한 경우 절대 경로로 지정하세요. 스크립트 경로만 바꿔도 작업 폴더가 자동으로 바뀌지는 않습니다.
  • 외부 명령의 stdin은 닫혀 있으므로 실행 중 질문에 답해야 하는 대화형 명령은 사용할 수 없습니다.

실행 중 q 또는 Ctrl + C로 닫으면 직접 실행한 subprocess도 종료합니다. 그 프로세스가 추가로 만든 하위 프로세스 전체를 관리하지는 않습니다.

파일 대신 pipe로 입력받고 싶다면

replay -는 표준 입력을 읽습니다. 이 모드는 항상 plain 보고서를 사용하며 입력이 끝난 뒤 결과를 출력합니다.

PowerShell · stdin 샘플
Get-Content tests/fixtures/successful_developer_run.jsonl | .\.venv\Scripts\agent-console.exe replay -
macOS / Linux · stdin 샘플
.venv/bin/agent-console replay - < tests/fixtures/successful_developer_run.jsonl

Agent Console은 credential을 관리하거나 이벤트 로그를 자동 저장하지 않습니다. message·metadata·stderr 원문은 표시하지 않으며 ID와 이벤트 종류는 표시됩니다. 실제 실행 로그를 저장소에 commit하지 마세요.

막혔을 때 확인할 것

python 또는 agent-console 명령을 찾을 수 없어요

Python 3.11 이상이 설치되어 있는지, 현재 폴더가 저장소 root인지 확인하세요. Windows에서 python 대신 py만 인식된다면 py -3 --version으로 버전을 확인한 뒤 py -3 -m venv .venv로 생성할 수 있습니다. 이후에는 안내서의 .venv 실행 경로를 그대로 사용하세요.

Activate.ps1 실행이 차단됐어요

이 안내서의 명령은 가상환경 활성화가 필요 없습니다. PowerShell 실행 정책을 바꾸지 않아도 .\.venv\Scripts\python.exe와 .\.venv\Scripts\agent-console.exe를 직접 실행할 수 있습니다.

화면 대신 글자 보고서만 나와요

출력이 terminal이 아니면 자동으로 plain mode가 됩니다. 일반 터미널에서 실행하거나 --tui를 사용하세요. run에서는 run --tui -- ...처럼 외부 명령을 구분하는 -- 앞에 옵션을 넣습니다. stdin replay는 plain mode만 지원합니다.

이벤트가 한꺼번에 나오거나 계속 기다려요

producer가 stdout을 buffering하고 있을 수 있습니다. Python 명령은 -u를 사용하거나 이벤트마다 flush하도록 설정하세요. plain mode는 입력 종료까지 기다립니다. terminal event를 보냈더라도 producer 프로세스가 계속 살아 있으면 구독도 계속됩니다.

Malformed JSON / Compatibility error가 보여요

stdout에 일반 문장이 섞였는지, 한 줄이 완전한 JSON event인지 확인하세요. 지원 버전은 schema_version: 1입니다. 잘못된 줄은 건너뛰고 다음 줄을 처리합니다.

Incomplete 또는 sequence gaps가 보여요

실행 종료 이벤트가 없거나 중간 이벤트가 누락됐습니다. producer의 종료 상태와 event log가 완전한지 확인하세요. Agent Console은 입력이 끝났다는 이유만으로 실행을 성공으로 처리하지 않습니다.

stderr가 있는데 내용은 보이지 않아요

민감 정보 노출을 줄이기 위해 수신 byte 수만 표시합니다. producer가 제공하는 별도의 안전한 진단 방법으로 원인을 확인하세요. 전체 run이 Completed여도 subprocess 종료 코드가 0이 아니면 CLI는 실패를 반환합니다.

터미널이 작거나 이벤트가 너무 많아요

창을 키우거나 --plain으로 실행하세요. TUI에는 최근 1,000개, plain에는 최근 200개 이벤트가 표시됩니다. 보관 한도는 session당 20개 run, run당 10,000개 이벤트이며 한도를 넘으면 명시적인 입력 오류로 보고합니다.

개발용 설정 선택 사항

사용만 한다면 여기까지 진행하지 않아도 됩니다. 코드를 수정하고 테스트하려면 개발 의존성을 설치하세요.

PowerShell · 개발 도구 및 검증
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\.venv\Scripts\python.exe -m pytest
.\.venv\Scripts\python.exe -m ruff check .
.\.venv\Scripts\python.exe -m ruff format --check .
git diff --check
macOS / Linux · 개발 도구 및 검증
.venv/bin/python -m pip install -e '.[dev]'
.venv/bin/python -m pytest
.venv/bin/python -m ruff check .
.venv/bin/python -m ruff format --check .
git diff --check

이 안내서는 저장소에 포함된 독립 HTML 파일입니다. 별도 서버나 외부 리소스 없이 브라우저에서 열 수 있습니다.
